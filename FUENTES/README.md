# FUENTES

Este directorio contiene los documentos y datos recopilados para el Observatorio de Conflictos Mineros.

La estructura propuesta es la siguiente:

- **investigaciones/**: Contiene investigaciones, trabajos u análisis realizados por el equipo. Por ejemplo, trabajos en PDF como "MASTER 1.pdf". Estos archivos no necesariamente se publicarán en la versión final, pero sirven como sustento interno.

- **usadas/**: Aquí se guardan las fuentes (pdf, xlsx, geojson, etc.) que se han utilizado en la construcción del observatorio. Todas las fuentes deberían tener un registro en `manifest.yaml` con metadatos de procedencia, fecha de acceso, licencia y uso.

- **manifest.yaml**: Archivo que documenta cada fuente o investigación incluida en este directorio, con su identificador, ruta local, URL original, fecha de acceso y notas de licencia.
