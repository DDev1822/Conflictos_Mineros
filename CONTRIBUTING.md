# Contribuir al observatorio

## Principios

1. Distingue hechos, interpretaciones y propuestas.
2. Añade al menos una fuente identificable por afirmación.
3. Registra autor o institución, fecha, URL, perspectiva y estado de verificación.
4. No clasifiques personas o actividades como ilegales sin fundamento jurídico verificable.
5. Declara relaciones profesionales, territoriales o económicas relevantes.

## Flujo

1. Abre un issue usando la plantilla apropiada.
2. Crea una rama y modifica los datos o narrativas correspondientes.
3. Ejecuta la validación completa descrita en el README.
4. Abre un pull request con el checklist de trazabilidad.

Las contribuciones de contenido se publican bajo CC BY 4.0 y el código bajo MIT.
