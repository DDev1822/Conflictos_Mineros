# Fuentes Usadas

Este subdirectorio contiene las fuentes externas (documentos, bases de datos, reportes) que se utilizan en el observatorio. Almacenar aquí las descargas asegura la trazabilidad y disponibilidad a largo plazo.

Cada fuente debería registrarse en el archivo `../manifest.yaml` con su identificador, ruta local, URL original, fecha de acceso y notas de licencia.
